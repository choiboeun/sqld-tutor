## A/B 테스트 결과 (Q11~Q13)

| | 테스터 A | 테스터 B | 테스터 C |
|---|---|---|---|
| 자동 설명 (24~27일) | 귀찮았다 | 귀찮았다 | 유용했다 |
| 직접 질문 (28~31일) | 더 집중해서 읽게 됐다 | 비슷했다 | 더 집중해서 읽게 됐다 |
| 어느 쪽이 더 도움? | **직접 질문** | **직접 질문** | **자동** |

2:1로 직접 질문 우세. 단, 테스터 C가 자동을 선택한 이유는 "자동이 더 좋아서"가 아니라 "되묻기 경로가 불안정해서 안전상 자동이 낫다"는 것 → 시스템 버그로 인한 선택 오염.

실질적으로 3명 모두 Q12에서 직접 질문이 "더 집중해서 읽게 됐다" 또는 "비슷했다"고 응답. 직접 질문이 나쁘다는 사람 없음.

## 결론

**A/B 테스트:** 직접 질문 방식이 집중도를 높인다는 공통 인식. 단, 되묻기 라우팅 버그가 직접 질문의 장점을 상쇄함. 버그 없는 환경이었다면 직접 질문 선호가 더 명확했을 것.

**학습 스타일 차이:** 테스터 B처럼 빠르게 문제 많이 풀고 싶은 유형은 자동/직접 차이를 크게 못 느낌. 학습 스타일에 따라 선호가 갈림.

**가장 큰 문제:** 테스터 C의 낮은 평가는 기능 문제가 아니라 난이도 재고 버그 + 라우팅 버그로 이틀간 앱을 못 쓴 것이 원인. 연구 보고서에 이를 분리해서 명기 필요.
