## ✓ 100문제 데이터셋이 검수된 상태로 존재하는가?

**결과:** ✅ 통과

**근거:**
- 파일 위치: `backend/app/data/questions/questions_v0.1.jsonl`
- 총 문제 수: **110문제** (목표 100문제 초과 달성)
- 자체 창작 문제로 구성 (저작권 위험 없음)

**검수 내용:**
- 문제 유형별 분류 완료
  - A유형 (단순 암기): 34문제
  - B유형 (SQL 문제): 해당 문제 포함
  - C유형 (개념 응용): 해당 문제 포함
  - D유형 (복합 응용): 해당 문제 포함
  - E유형 (ERD/다이어그램): 3문제
- 난이도 확정 완료 (교수님 동의 획득)
  - 하: A유형 34문제
  - 중: C·D유형 40문제
  - 상: B·E유형 36문제
- JSONL 스키마 전 필드 검증 완료: `id`, `category`, `difficulty`, `question_type`, `context`, `question`, `options`, `answer`, `hint`, `explanation`, `tags`
- 11개 카테고리 전 범위 커버 (2024년 개정 기준)

## ✓ LangGraph 그래프 1개가 CLI에서 작동하는가?

**결과:** ✅ 통과

**근거:**
- 실행 명령: `cd backend && .venv/bin/python3 -m app.main_cli`
- 직접 테스트 확인 결과:
  - "문제 줘" 입력 → `generate_sqld_question` 도구 호출 → 문제 출제 정상 동작
  - 번호로 답 입력 → 채점 및 해설 정상 동작
  - 같은 `thread_id`로 재실행 시 대화 이어짐 (MemorySaver 동작 확인)
- LangSmith trace 확인 완료
  - 프로젝트: `sqld-tutor`
  - Thread ID `test-session-1` — 9 turns 기록
  - chatbot → tools → chatbot 노드 흐름 정상 기록

**그래프 구조:**
```
START → chatbot → (tool_calls 있으면) tools → chatbot → END
                → (없으면) END
```
