## 사용자 A·B (SQLD 수험생 2명)

**버그**
- 연속 정답 후 "다른 카테고리로 넘어갈게요" 안내 후 자동으로 문제가 나오지 않음 (직접 요청해야 함)
- "모르겠다" 입력 시 설명 중 갑자기 문제로 바뀌는 현상
- 같은 문제 정답 판정 불일치 (처음엔 오답, 재시도 시 정답으로 처리)
- 로그아웃 후 재로그인 시 풀이 기록 사라짐

**UX 개선 요청**
- 메시지 전송 후 입력창 포커스 자동 해제 → 연속 입력 시 불편
- 오답 회고 기능 (풀이 기록 다시 보기)

**긍정 반응**
- AI 개념 설명이 타 문제은행과의 차별점으로 인식됨
- 회원가입·로그인·진단 흐름은 어려움 없이 이해
- 전반적인 사용 경험 양호, 개선되면 더 자주 쓸 것 같다는 의견

## 사용자 C (컴공 전공·개발·QA 경험자)

**온보딩·UX**
- 온보딩 설문 후 채팅창에서 비전공자 이탈 가능성 있음 (첫 화면에서 무엇을 해야 할지 안내 부족)
- 회원가입 후 자동 로그인 미지원
- 이메일 브랜딩 미설정

**문제 풀이 흐름**
- 문제에 대한 추가 질의 창/모달/버튼 필요 (NotebookLM처럼) — 문제 오류 확인 경로가 부족해 타 AI 서비스로 이탈 유발
- 번호 답변인데 자유 입력창만 있음 → 문제 유형에 따라 입력 방식이 유동적으로 바뀌어야 함
- "2 2 3 4"처럼 다중 입력 시 간헐적으로 정답 처리되는 버그
- 네트워크 오류 시 재시도 버튼 부재 + 인디케이터 부실

**성능**
- 페이지 전환 후 스켈레톤 로딩 방식 도입 권장 (답답함 → 이탈)

**기능 제안**
- 개념 설명 하단 "더 쉽게 / 더 전문적으로" 버튼
- 문제 풀이 중 "너무 어려워요 / 너무 쉬워요" 난이도 조절 버튼
- 예상 점수 표시 기능 (독창성·차별화 포인트)
- 지속 학습 유도 장치 (듀오링고처럼 흥미 유발)

**전체 총평**
- UX·UI 부족으로 일반 AI 플랫폼 직접 사용이 더 편하다는 인식을 줄 수 있음
- 직관성과 지속 사용 유도 장치 보완 필요
