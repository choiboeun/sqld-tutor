## 발견된 버그

### 버그 1 — SQL 보기 회색 박스 오분류 (1차)
- **현상:** 한국어 텍스트 보기(4번)에 SQL 코드 블록 스타일의 회색 박스가 적용됨
- **원인:** `_SQL_IN_OPTION` 정규식이 `\bSELECT\b`로 문장 중간의 SQL 키워드도 감지
- **수정:** `^\s*(?:SELECT|INSERT|...)` — 줄 시작 기준으로 교체 (commit `cec5613`)

### 버그 2 — pending 문제 중 카테고리 변경 요청 무반응 (2차)
- **현상:** 문제가 출제된 상태에서 "관리 구문 문제 줘"라고 하면 문제만 다시 표시되고 안내 없음
- **원인:** 비숫자 입력 시 prefix가 빈 문자열로 설정됨
- **수정:** "현재 문제에 먼저 답해주세요 (1~4번)." 안내 메시지 추가 (commit `cbc6d20`)

## 주요 피드백 요약

**긍정적:**
- "SQLD에 관한 것이라는 걸 바로 알겠어요" — 앱 목적 즉시 인지 (1차)
- "기준이 있어서 알기 편했어요" — 목표 점수 선택 화면의 점수 기준 설명이 도움됨 (1차)
- "제가 취약한 부분을 설명해 준다고 해서 친절하다고 느꼈어요" — 진단 결과 화면 반응 (1차)
- "심플하고 좋은 것 같아요" — 전체 디자인 (1차)
- "문제를 모르겠는 거 말곤 헷갈린 순간 없었어" (2차)
- "태블릿도 되더라!" (2차)
- "개념 정의 해주는 것도 좋네!" (2차)
