## 테스터 1 피드백

**SQLD 62회 응시 예정 수험생**

**버그**
- 오답 복습 시 선택지 버튼(1~4번)이 표시되지 않고 직접 텍스트로 입력해야 함 (QA-10과 동일)

**UX 개선 요청**
- 오답 복습 시 완전히 같은 문제 재출제가 아니라 살짝 변형된 유사 문제를 풀고 싶다
- 문제를 풀고 나서 다음 문제를 받으려면 입력창에 직접 "문제 줘"를 입력해야 해서 번거롭다 → "다음 문제" 버튼 원함
- 문제 풀이 중이나 추가 질의 중 하단 버튼들이 사라짐 → 항상 보이거나 "다음 문제" / "오답 복습" 버튼으로 바로 진행 가능해야 함

## 테스터 2 피드백

**SQLD 62회 응시 예정 수험생**

**UX 개선 요청**
- 문제를 하나 풀고 나서 다음 문제를 받으려면 "문제 줘"라고 직접 입력해야 해서 번거롭다 → 버튼 제공 원함 (테스터 1과 동일)
- 채팅 시작 시 표시되는 제안 칩 버튼("문제 풀기", "복습하기" 등)이 대화가 이어지면 사라지는데, 계속 유지되거나 쉽게 접근할 수 있으면 더 편할 것 같다
