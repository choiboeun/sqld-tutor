## 1. 연구 배경 및 목적

### 1.1 문제 정의

SQLD(SQL Developer) 자격증은 국가공인 데이터베이스 자격증으로, 데이터 직군 취업 준비생과 재직자에게 널리 요구된다. 그러나 기존 학습 방식에는 다음과 같은 문제가 있다.

- **취약점 파악 어려움:** 어느 카테고리가 약한지 스스로 진단하기 어렵다 (인터뷰 4/5명 응답)
- **개념→문제 적용 갭:** 개념을 알아도 실전 문제에 적용하지 못한다 (4/5명)
- **오답 복습 비효율:** 틀린 문제를 체계적으로 재복습할 방법이 없다 (3/5명)
- **해설 불충분:** 왜 틀렸는지 이해하기 어렵다 (3/5명)

이 프로젝트는 위 페인포인트를 해결하는 **LangGraph 기반 적응형 AI 튜터**를 설계·구현하고, 실사용자 베타 테스트를 통해 효과를 검증하는 것을 목표로 한다.

### 1.2 연구 질문

1. AI 튜터가 사용자의 약점 카테고리를 정확히 진단하고 맞춤 문제를 제공할 수 있는가?
2. 반복 학습을 통해 약점 카테고리 정답률이 향상되는가?
3. LLM 기반 개념 설명이 사용자가 체감할 수 있는 수준의 품질을 갖추는가?

## 2. 시스템 설계 및 구현

### 2.1 기술 스택

| 레이어 | 기술 | 선택 이유 |
|--------|------|-----------|
| AI Agent | LangGraph (Python) | 상태 기반 멀티노드 대화 흐름 제어 |
| LLM | Claude Sonnet 4.6 (Anthropic) | 한국어 SQLD 문맥 이해 품질 |
| Backend | FastAPI + SSE | 토큰 단위 스트리밍 응답 |
| Frontend | Next.js 14 (App Router) | SSE 수신 및 실시간 UI 렌더링 |
| DB / Auth | Supabase (PostgreSQL) | 인증 + 학습 데이터 영속성 |
| Memory | LangGraph PostgresSaver | 대화 체크포인트 영속 저장 |
| RAG | Chroma DB + Gemini Embedding | 카테고리별 개념 검색 |
| Observability | LangSmith | LLM 트레이스 모니터링 |

### 2.2 LangGraph 에이전트 구조

시스템은 다음 7개 노드로 구성된다.

```
사용자 입력
    ↓
intent_classifier  → 의도 분류 (drill / review / explain / diagnose / sql / follow_up)
    ↓
[분기]
├── chatbot_node    → 일반 대화 + 도구 호출
├── drill_node      → 문제 출제 + 채점
├── review_node     → 오답 복습
├── explain_node    → RAG 개념 설명
├── diagnose_node   → 약점 분석 리포트
└── sql_node        → SQL 실행 샌드박스
    ↓
state_updater       → 정답률·streak·약점 업데이트
    ↓
adaptive_difficulty_router → 다음 난이도·카테고리 결정
```

### 2.3 적응형 학습 알고리즘

- **진단 8문제:** 목표 점수(60/70/80/90점)별 가중치로 난이도 자동 선택
- **진단 후:** 카테고리별 정답률 기반 자동 난이도 조정 (70%↑→상, 40~70%→중, 40%↓→하)
- **카테고리 전환:** 동일 카테고리 3연속 정답 시 다음 약점 카테고리로 자동 전환
- **오답 즉시 설명:** 오답 발생 시 RAG 기반 개념 설명 자동 트리거

### 2.4 문제 은행

- 총 220문제 (11개 카테고리 × 20문제)
- 2024년 SQLD 개정 기준 (절차형 SQL 삭제, TOP N/PIVOT/정규표현식 추가)
- 난이도 분류: 하(A유형) / 중(C·D유형) / 상(B·E유형)
