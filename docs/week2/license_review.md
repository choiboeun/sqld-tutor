## 1. 한국데이터산업진흥원 자료 활용 범위 검토

**검토일:** 2026-05-11
**검토 대상:** dataq.or.kr 이용약관, SQLD 기출문제 활용 가능 여부

### 확인 내용
dataq.or.kr 이용약관 제15조 확인 결과:
- 사이트 내 모든 저작물의 저작권은 한국데이터산업진흥원에 귀속됨
- 사전 승낙 없이 복제, 배포, 영리 목적 이용 금지
- 교육/학술 목적이라도 별도 허용 조항 없음

### 프로젝트에서 실제로 사용할 자료

| 자료 | 사용 계획 | 저작권 문제 여부 |
|------|---------|--------------|
| SQLD 기출문제 | 사용 안 함. GPT-4o로 자체 생성 | 해당 없음 |
| SQLD 공식 문제집 | 사용 안 함. GPT-4o로 자체 생성 | 해당 없음 |

### 결론
dataq.or.kr 저작물을 직접 프로젝트에 사용하는 항목이 없으므로
저작권 침해 가능성 없음. 문의 메일 발송 불필요.

## 2. 시중 SQLD 문제집 활용 범위 검토

**검토일:** 2026-05-12

### 검토 대상: 이기적 SQLD 부록 (또기적 합격자료집)

**입수 경로:** 이기적 블로그 신청 후 무료 수령 (PDF)  
**출판사 / 저작권자:** 영진닷컴  
**저작권 고지:** "저작권자의 허락 없이 도서의 내용을 그대로 복사하여 다른 출판물이나 온라인에 게재하는 것은 저작권법 위반에 해당합니다"

### 자료 분석 결과

| 항목 | 내용 |
|------|------|
| 자료 유형 | 실습형 문제 (SQL 직접 작성) |
| 실제 시험 형식 | 객관식 4지선다 50문항 |
| 기출문제 여부 | **기출문제 아님** — 저자가 별도 제작한 연습 문제 |
| 포함 내용 | sample_data.sql (Oracle), 실습 문제, 정답 SQL |
| 활용 가능 여부 | 문제 직접 복사/사용 불가 |

### 프로젝트 활용 판단

| 활용 방식 | 가능 여부 | 사유 |
|-----------|----------|------|
| 문제 직접 복사 → 문제 은행 탑재 | **불가** | 저작권 침해 |
| 출제 토픽 참고 (어떤 개념이 다뤄지는지) | **가능** | 아이디어 참고는 저작권 해당 없음 |
| 문제 형식 참고 (GPT-4o 생성 시 포맷 가이드) | **가능** | 동일 이유 |
| SQL 실습 환경 구성 참고 (sample_data.sql 구조) | **가능** | Oracle 표준 SQL로 작성된 공통 구조 |

### 결론

또기적 자료는 실습형(SQL 직접 작성) 문제로, 실제 SQLD 시험 형식(객관식)과 다르며 기출문제가 아님.  
문제 직접 사용 불가, **토픽 목록 및 형식 참고 용도로만 활용.**  
별도 저작권 문의 불필요.

## 3. GPT-4o 생성 문제의 저작권

**검토일:** 2026-05-13

### 저작권 귀속

OpenAI 이용약관(Terms of Use) 기준:
- GPT-4o 출력물에 대한 권리는 **사용자(프롬프트 입력자)에게 귀속**
- 단, GPT-4o가 타인의 저작물을 그대로 재현한 경우 예외 적용

→ 프로젝트에서 GPT-4o로 생성한 문제의 저작권은 **프로젝트 운영자 본인에게 귀속**

### SQLD 형식/개념 참고의 합법성

| 항목 | 판단 | 근거 |
|------|------|------|
| SQLD 시험 형식(객관식 4지선다) 참고 | **합법** | 형식·아이디어는 저작권 보호 대상 아님 |
| SQLD 출제 개념(JOIN, 윈도우 함수 등) 참고 | **합법** | 개념 자체는 저작권 보호 대상 아님 |
| 기존 문제 문장을 그대로 복사 | **불법** | 표현물 복제는 저작권 침해 |

→ GPT-4o로 자체 생성 시 기존 문제 표현을 복사하지 않으므로 저작권 침해 없음

### 신뢰성 확보 방안

GPT-4o 생성 문제는 창작 문제이므로 오류 가능성 존재.  
**SQLD 합격자(운영자 본인)가 전수 검수**하여 오류 문제 제거 후 문제 은행 탑재.

### 결론

GPT-4o로 생성한 문제는 저작권상 문제 없음.  
단, 생성 품질 보장을 위해 합격자 검수 프로세스 필수 적용.
