## 4. 배분 근거 상세

**1. 데이터 모델링 기초 → A:9, E:1**  
교차 분석 17문항 중 A:15(88%), E:2(12%). 1과목 순수 개념 영역으로 SQL 코드가 등장할 수 없음. ERD 도식을 주고 틀린 설명 고르는 E유형 1개.

**2. 데이터 모델과 SQL → A:8, E:2**  
교차 분석 4문항으로 표본 부족. A:3(75%), E:1(25%) 비율 기반, 정규화·NULL속성·본질/인조식별자는 개념형이 압도적이며 ERD가 간헐적으로 등장하는 주제 특성 반영.

**3. SELECT & WHERE → A:1, B:4, C:1, D:4**  
교차 분석 7문항: A:14%, B:43%, D:43%. WHERE 조건 빈칸(C) 유형은 데이터에 없었으나 실제 시험에서 가능한 형식이므로 1개 추가. A·B·D 균형 반영.

**4. 함수 → A:1, B:2, C:2, D:5**  
교차 분석 9문항: A:11%, B:22%, C:22%, D:44%. NVL·DECODE·COALESCE 등 함수는 "어떤 SQL 결과가 다른가", "어떤 SQL이 올바른가"(D유형)가 많음. 데이터 비율 그대로 반영.

**5. GROUP BY & ORDER BY → A:2, B:4, C:2, D:2**  
교차 분석 4문항으로 표본 부족(B:50%, C:25%, D:25%). HAVING·집계함수 개념(A) 2개 추가하고 B 비중 높게 유지. 전체 유형 고르게 배분.

**6. 조인 → A:2, B:5, C:2, D:1**  
교차 분석 7문항: A:29%, B:57%, C:14%. 조인은 두 테이블 주고 결과 예측(B)이 압도적. 빈칸완성(C)은 LEFT OUTER JOIN 등 조인 유형 채우기. 데이터 비율 반영해 B 높게 설정.

**7. 서브쿼리 & Top N → A:1, B:3, C:1, D:5**  
교차 분석 9문항: A:11%, B:33%, D:44%. 서브쿼리는 "어떤 SQL이 오류인가", "어떤 SQL이 올바른가"(D유형) 비중이 높음. Top N은 빈칸완성(C) 추가. 데이터 비율 반영.

**8. 집합 연산자 & 그룹 함수 → A:1, B:6, C:3**  
교차 분석 7문항: A:14%, B:57%, C:29%. ROLLUP·CUBE·GROUPING SETS 실행결과 예측(B)이 압도적. 데이터 비율 그대로 반영.

**9. 윈도우 함수 → A:2, B:3, C:5**  
교차 분석 7문항: A:14%, B:29%, C:43%. ROWS/RANGE 구문 빈칸(C)과 RANK·FIRST_VALUE 실행결과(B)가 핵심. 데이터 비율 반영.

**10. SQL 활용 기타 → A:1, B:3, C:6**  
교차 분석 7문항: A:14%, B:29%, C:57%. 계층형 질의(PRIOR 빈칸), PIVOT 빈칸, 정규 표현식 패턴이 모두 C유형. 데이터에서 C 비중이 가장 높게 나타남.

**11. 관리 구문 → A:6, B:3, C:1**  
교차 분석 15문항(가장 많은 표본): A:60%, B:27%, C:7%. DML·TCL·DDL·DCL 특성상 "TRUNCATE는 DDL이다" 같은 개념형(A)이 압도적. 60회차에서 관리구문 8문항 중 A가 7문항으로 확인됨.

## 5. 분석 한계 명시

### 한계 발생 원인
SQLD 시험은 총 50문제로 구성되며, 이를 11개 카테고리로 나누면 카테고리당 평균 4~8문제에 불과하다. 본 분석에서는 현행 범위(2024년 개정 이후) 기준으로 두 회차(7회차 유효 46문항 + 제60회 50문항)를 수집하여 총 96문항을 교차 분석하였으나, 카테고리별 표본이 최소 4문항에서 최대 17문항으로 통계적 유의성에 한계가 있다.

### 근거 수준 정리

| 항목 | 근거 수준 | 세부 내용 |
|------|---------|---------|
| 전체 유형 비율 | 데이터 기반 | 7회차(유효 46개) + 60회차(50개) = 96문항 분석 |
| 카테고리별 배분 (표본 8개 이상) | 데이터 기반 | 데이터 모델링 기초(17개), 관리구문(15개) |
| 카테고리별 배분 (표본 4~7개) | 데이터+보완 | 비율 참고 후 주제 특성으로 소수 보완 |
