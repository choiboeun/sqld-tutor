## 3. 주요 특징 및 인사이트

### 시각 자료 포함 비율
- 테이블, SQL 코드, ERD 중 하나 이상이 지문에 포함된 문제: 약 **68%** (34개)
- 순수 텍스트만의 개념형: 약 **32%** (16개)
- → GPT-4o 생성 문제의 약 70%는 테이블 또는 SQL 코드를 포함해야 실제 시험과 유사

### 빈칸 완성형 비율이 높음
- 전체의 18%가 SQL 빈칸 채우기 형식
- 단순 개념 암기가 아닌 SQL 구문 이해를 요구
- → GPT-4o 프롬프트에 빈칸 완성형 비율 명시 필요

### 1과목 vs 2과목 출제 비중
- 1과목(데이터 모델링): 10문항, 거의 전부 개념형 (A유형)
- 2과목(SQL): 40문항, B/C/D/E/F 유형 골고루 분포

## 4. 주의 사항 — 2024년 개정 영향

SQLD는 2024년에 출제 범위가 개정됨. 분석한 7회차 기출에는 **개정 전 삭제된 범위의 문제가 포함**되어 있음.

| 문제번호 | 주제 | 개정 결과 |
|----------|------|----------|
| 11번 | 해시 조인 (조인 수행 원리) | **삭제** |
| 24번 | PL/SQL (절차형 SQL) | **삭제** |
| 36번 | 실행계획 (옵티마이저) | **삭제** |
| 38번 | 인덱스 스캔 | **삭제** |

**2024년 개정으로 삭제된 항목 (GPT-4o 생성 시 제외):**
- 절차형 SQL 전체 (PL/SQL, 프로시저, 트리거 등)
- SQL 최적화 기본 원리 전체 (옵티마이저, 실행계획, 인덱스 기본, 조인 수행 원리)

**2024년 개정으로 추가된 항목 (GPT-4o 생성 시 포함):**
- TOP N 쿼리
- PIVOT 절과 UNPIVOT 절
- 정규 표현식
- 표준 조인 (SQL 기본으로 이동)
- 관리 구문 챕터 신설 (DML, TCL, DDL, DCL)

→ 7회차 기출 50문제 중 실제 현행 범위는 46문제 기준으로 봐야 함.

## 6. 절차형 SQL 포함 여부 재검토

- 공식 출제 범위(dataq.or.kr) 기준: 절차형 SQL 항목 없음
- 책 출제 경향 빈출 태그: SQL 활용에 "절차형" 포함
- 7회차 기출 24번: PL/SQL 개념 문제 등장

**판단:** 실제 시험에서는 절차형 SQL 개념 문제가 여전히 출제될 가능성 있음.  
GPT-4o 문제 생성 시 PL/SQL 절차 문법(DECLARE, BEGIN 등) 작성 문제는 제외하되,  
절차형 SQL의 **개념/특징을 묻는 문제**는 소수 포함 검토.
