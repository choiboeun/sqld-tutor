### 🥇 1위. 내 취약점이 무엇인지 스스로 파악하기 어렵다

**한 줄 정의:**
> 열심히 공부하고 문제를 풀어도, 내가 어떤 개념이 부족한지 전체적인 그림이 보이지 않는다.

**발생 상황:**
- 문제집을 다 풀고 나서 어디를 더 공부해야 할지 모를 때
- 틀린 문제들을 봐도 패턴이 보이지 않을 때
- JOIN이 약한 건지, 서브쿼리가 약한 건지 구분이 안 될 때

**근거 — 설문 응답:**

> "AI가 취약한 부분을 짚어서 알려주면 빈틈을 보완할 수 있으니 시간 단축에 도움이 될 것 같다." — 참여자 1

> "특화된 AI를 사용한다면 능률이 오를 것 같다." — 참여자 4

> "내가 어떤 개념이 부족한지 스스로 파악하기가 정말 어려웠어요. JOIN이 약한 건지, 서브쿼리가 약한 건지 큰 그림이 안 보였거든요." — 참여자 5

**근거 — 개발자 본인 경험:**

> SQL 활용 영역(JOIN, 서브쿼리, 윈도우 함수)에서 많이 틀렸지만, 공부 중에는 어느 부분이 얼마나 부족한지 수치로 파악하기 어려웠다.

**언급 수:** 설문 3명 + 개발자 본인 = 총 4건

**현재 사용자 대처 방법:**
- 틀린 문제를 직접 표시하고 재풀이
- AI(ChatGPT)에게 개별적으로 물어봄
- 특정 카테고리 위주로 감에 의존해 추가 학습

**현재 방법의 한계:**
- 전체 학습 진도 중 어느 부분이 얼마나 취약한지 수치로 파악 불가
- 감에 의존하다 보니 실제 약점이 아닌 곳에 시간을 낭비할 수 있음

**서비스에 주는 시사점:**
AI 튜터가 문제 풀이 기록을 누적하여 카테고리별 정확도를 자동으로 계산하고, 취약 카테고리를 명확하게 진단해주는 기능이 핵심이다. 단순히 문제를 내주는 것이 아니라 **"당신은 윈도우 함수가 38% 정확도입니다"** 와 같은 구체적인 피드백이 필요하다.

### 🥈 2위. 개념은 이해했는데 막상 문제에 적용이 안 된다

**한 줄 정의:**
> 개념 설명을 듣고 이해했다고 생각했지만, 실제 문제를 풀 때 적용하지 못하는 갭이 존재한다.

**발생 상황:**
- 인강이나 해설을 보고 "이해했다"고 느꼈지만 비슷한 문제에서 또 틀릴 때
- SQL 문법은 아는데 복잡한 쿼리를 해석하려니 막힐 때
- 개념을 암기는 했는데 실제 문제 상황에 어떻게 쓰는지 모를 때

**근거 — 설문 응답:**

> "개념과 문제의 연계성을 찾기 힘듦" — 참여자 1

> "문제 적용 과정이 따라가기 힘들었음" — 참여자 3

> "인강을 들어도 개념은 알겠는데 막상 문제에 적용하려니 막히고" — 참여자 5

**근거 — 개발자 본인 경험:**

> 기초 SQL 문법은 데이터베이스 수업에서 이미 배웠지만, JOIN과 서브쿼리가 중첩된 복잡한 SQL문을 해석하는 데 오랜 시간이 걸렸다. 개념을 아는 것과 문제에서 빠르게 적용하는 것은 전혀 다른 능력이었다.

**언급 수:** 설문 3명 + 개발자 본인 = 총 4건

**현재 사용자 대처 방법:**
- 해설을 반복해서 읽기
- 비슷한 문제를 더 찾아서 풀기
- ChatGPT에게 개념을 다시 설명해달라고 요청

**현재 방법의 한계:**
- 반복 독해만으로는 적용력이 늘지 않음
- 비슷한 문제를 직접 찾아야 하는 번거로움
- ChatGPT 설명이 길고 시험 맥락과 달라 핵심 파악이 어려움

**서비스에 주는 시사점:**
개념 설명 후 즉시 해당 개념을 적용하는 문제를 출제하는 흐름이 필요하다. **"개념 설명 → 예시 문제 1개 → 확인 문제 2~3개"** 의 순서로 연결하여 이해와 적용 사이의 갭을 줄여야 한다.

### 🥉 3위. 오답 복습이 번거롭고 자동화가 안 된다

**한 줄 정의:**
> 틀린 문제를 다시 보고 싶어도 직접 수작업으로 분류해야 하며, 어떤 유형에서 얼마나 틀렸는지 한눈에 파악이 안 된다.

**발생 상황:**
- 문제집에 오답 표시를 해두었지만 나중에 다시 찾아볼 때 번거로울 때
- 틀린 문제들이 어떤 카테고리에 몰려있는지 파악하고 싶을 때
- 오답노트를 직접 만들어야 하는 수작업이 부담스러울 때

**근거 — 설문 응답:**

> "틀린 오답 따로 빼고 그 부분만 반복해서 보기" (수작업으로 직접 분류 중) — 참여자 1

> "틀린 문제는 문제집에 체크해두고 나중에 다시 풀거나, 모르는 개념은 ChatGPT한테 물어봤어요. 그런데 문제집에 체크만 해두면 나중에 어떤 유형에서 많이 틀렸는지 한눈에 파악이 안 되고..." — 참여자 5

> "틀린 문제만 자동으로 모아서 다시 풀 수 있는 기능이 있었으면 좋겠다고 느꼈어요." — 참여자 5

**근거 — 개발자 본인 경험:**

> 문제집을 사용하면서 틀린 문제들만 다시 보고 싶었지만, 책이다 보니 쉽지 않았다. 틀린 문제에서 나온 개념들만 모아주면 더 효율적이었을 것이라고 생각했다.

**언급 수:** 설문 2명 + 개발자 본인 = 총 3건

**현재 사용자 대처 방법:**
- 문제집에 직접 체크 표시
- 오답노트를 손으로 작성
- AI에게 개별적으로 재질문

**현재 방법의 한계:**
- 수작업이므로 시간과 노력이 많이 소요
- 유형별/카테고리별 분류가 안 됨
- 종이 문제집의 구조적 한계

**서비스에 주는 시사점:**
틀린 문제를 자동으로 저장하고, 카테고리별로 분류하여 오답 모음 세트를 자동 생성하는 기능이 필요하다. 사용자가 원할 때 **"오답만 모아서 다시 풀기"** 세션을 바로 시작할 수 있어야 한다.

### 4위. 해설이 불충분하여 왜 틀렸는지 이해가 안 된다

**한 줄 정의:**
> 문제집 해설이 너무 간단하거나, AI 설명이 너무 길어서 틀린 이유를 명확하게 이해하기 어렵다.

**발생 상황:**
- 문제집 해설을 읽었는데도 왜 그 답이 맞는지 납득이 안 될 때
- "정답은 B다" 수준의 해설만 있고 개념 설명이 없을 때
- ChatGPT에게 물어봤더니 너무 길게 설명해서 오히려 핵심을 놓칠 때

**근거 — 설문 응답:**

> "문제 풀이에 대한 자세한 설명" (부족함을 불편으로 언급) — 참여자 2

> "문제집 해설이 너무 간단하게 나와 있어서 왜 틀렸는지 이해가 안 될 때가 많았어요." — 참여자 5

**근거 — 개발자 본인 경험:**

> 틀린 문제에서 출제자의 의도를 파악하고 내가 어떤 개념이 부족했는지 알고 싶었는데, 문제집 해설만으로는 부족해서 직접 분석해야 했다.

**언급 수:** 설문 2명 + 개발자 본인 = 총 3건

**현재 사용자 대처 방법:**
- 해설을 반복해서 읽기
- ChatGPT에게 추가 설명 요청
- 유튜브에서 관련 강의 검색

**현재 방법의 한계:**
- 문제집 해설은 분량 제한으로 설명이 짧음
- ChatGPT 설명은 너무 길거나 시험과 맥락이 다름
- 유튜브 검색은 시간이 오래 걸림

**서비스에 주는 시사점:**
틀렸을 때 단순히 "정답은 B"가 아니라, **"당신이 이 문제를 틀린 이유는 JOIN ON 조건을 WHERE 절과 혼동했기 때문입니다"** 와 같이 원인 중심의 설명이 제공되어야 한다. 설명의 길이도 핵심만 담아 간결해야 한다.

### 5위. 내 공부 방식이 맞는지 확신이 없다

**한 줄 정의:**
> 스스로 학습 방향을 정해야 하는 상황에서, 이 방법이 합격으로 이어질지 불안함을 느낀다.

**발생 상황:**
- 문제집을 풀고 있는데 이게 효율적인 방법인지 모를 때
- 남은 시험까지 얼마나 준비가 됐는지 객관적으로 알 수 없을 때
- 합격에 필요한 점수 대비 현재 실력이 어느 정도인지 가늠이 안 될 때

**근거 — 설문 응답:**

> "공부 방식이 이게 맞을지에 대한 의문점" — 참여자 4

**언급 수:** 설문 1명 + 개발자 본인 참고

> **주의:** 현재 설문 응답자 1명만 명확히 언급한 페인포인트로, 이를 일반화하기에는 근거가 부족하다. 향후 추가 인터뷰에서 검증이 필요한 가설로 기록한다.

**현재 사용자 대처 방법:**
- 합격 후기 블로그 검색
- 주변 합격자에게 조언 구하기
- 유튜브 공부법 영상 참고

**현재 방법의 한계:**
- 타인의 방법이 본인에게 최적화되어 있지 않음
- 개인의 취약점을 반영한 맞춤형 학습 경로가 없음

**서비스에 주는 시사점:**
진단 테스트를 통해 현재 실력을 수치화하고, **"현재 정확도 기준으로 3주 후 시험에서 합격 가능성이 높습니다"** 와 같은 예측과 학습 경로 제안 기능이 있다면 이 페인포인트를 해소할 수 있다. 단, 1명의 응답이므로 우선순위는 상위 4개 다음으로 설정한다.

## 페인포인트와 핵심 기능 연결

```
페인포인트 1 (취약점 파악)
    → AI가 카테고리별 정확도를 자동 추적
    → "당신의 약점은 윈도우 함수입니다" 진단

페인포인트 2 (개념→문제 갭)
    → 개념 설명 직후 관련 문제 자동 출제
    → 맞을 때까지 유사 문제 반복 제공

페인포인트 3 (오답 복습 비효율)
    → 틀린 문제 자동 저장 및 카테고리 분류
    → 오답 모음 재복습 세션 원클릭 시작

페인포인트 4 (해설 불충분)
    → 틀린 이유를 개념 단위로 설명
    → 핵심만 담은 간결한 해설 제공

페인포인트 5 (공부 방향 불확실)
    → 진단 기반 학습 경로 자동 제안
    → 현재 실력 수치화 및 합격 가능성 안내
```
