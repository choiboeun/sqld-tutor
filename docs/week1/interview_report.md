## 4. 종합 인사이트

### 인사이트 1. ChatGPT는 이미 쓰고 있지만 SQLD에 특화되지 않아 불만족
- 응답자 5명 중 4명(80%)이 ChatGPT를 학습에 활용 중
- 그러나 참여자 1과 5는 구체적인 불만 언급
  - 신뢰성 없는 자료 제공
  - 설명이 길고 시험 출제 경향과 맞지 않음
- **시사점:** "SQLD에 특화된 AI"라는 포지셔닝 자체가 명확한 차별점

### 인사이트 2. 개념 이해와 문제 적용 사이의 갭이 공통 어려움
- 참여자 1, 3, 5 (3명) 모두 "개념은 알지만 문제에 적용이 안 된다"고 언급
- 이는 단순 암기식 학습의 한계를 보여줌
- **시사점:** 개념 설명 후 즉시 연결 문제를 제공하는 흐름 설계가 필요

### 인사이트 3. 오답 복습은 하고 싶지만 자동화 도구가 없음
- 참여자 대부분이 오답 복습의 중요성을 인지하고 있으나
- 현재는 수작업(노트 정리, 문제집 체크)에 의존
- **시사점:** 오답 자동 수집 및 재복습 기능이 핵심 기능이 될 수 있음
